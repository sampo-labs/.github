# Sampo Labs LLC

We build focused software for manufacturers — from the ERP backlog down to the machine's serial port.

## What We Do

Modern factories run on a patchwork of systems: ERP platforms holding the plan, PLCs and CNCs holding the physical state, and very little reliable glue between them. Sampo Labs closes that gap. We design and ship production-grade software that connects business logic to the shop floor, one well-scoped problem at a time.

Our work spans the full vertical:

| Layer | Examples |
|---|---|
| **ERP & planning** | Work order sync, production scheduling, inventory feeds |
| **MES & execution** | Job tracking, operator UIs, quality checkpoints |
| **Machine integration** | Serial port drivers, OPC-UA adapters, PLC data bridges |
| **Data & visibility** | Real-time dashboards, cycle-time analytics, traceability |

## How We Work

- **Focused scope** — we solve the problem in front of us completely before moving to the next one.
- **Close to the metal** — integrations go all the way down: RS-232, Modbus, proprietary vendor protocols.
- **Boring reliability** — manufacturing uptime is non-negotiable, so we favour proven patterns and explicit error handling over clever abstractions.
- **Iterative delivery** — small shippable increments that operators can start using before the full vision is complete.
